 Sentiment Analysis Using Machine Learning

 Project Overview

This project is a Sentiment Analysis application developed using Python and Machine Learning techniques. The system analyzes textual data such as restaurant reviews, social media posts, or product reviews and classifies them into Positive, Negative, or Neutral sentiments.

 Objective

The main objective of this project is to build a machine learning model capable of understanding and predicting the sentiment expressed in a piece of text.

* Pandas
* NumPy
* NLTK
* Scikit-learn
* Jupyter Notebook

 Libraries Used

 Project Workflow

1. Data Collection
2. Data Preprocessing
   * Text Cleaning
   * Tokenization
   * Stopword Removal
   * Stemming/Lemmatization
3. Feature Extraction using TF-IDF
4. Model Training
5. Model Evaluation
6. Sentiment Prediction
 Machine Learning Techniques

* TF-IDF Vectorization
*  Naive Bayes
* Accuracy Evaluation
* Classification Report
* Confusion Matrix

 Features

* Classifies text into Positive, Negative, or Neutral sentiment.
* Handles text preprocessing automatically.
* Provides sentiment predictions for custom user input.
* Evaluates model performance using standard metrics.

 Results

The model was trained and tested on a review dataset and achieved satisfactory accuracy in sentiment classification tasks.
